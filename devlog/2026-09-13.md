# 2026-09-13 修复与功能新增

## 本轮范围

审查后按问题清单修复 Python 版（`ping_tool/`），并新增「一键关闭 Windows 防火墙」。
C++ 实验版（`ping-tool-cpp/`）本轮按用户要求不动。

## 缺陷修复

| 问题 | 位置 | 修复方式 |
|------|------|----------|
| 删除中间目标后再添加，卡片网格行号冲突（互相遮挡） | `ui/app.py` `_add_card` | 行号改为只增不减的 `_next_row` 计数器；新增回归测试，已验证旧写法会失败 |
| 保留地址可被等价写法绕过（`0:0:0:0:0:0:0:1`、`0000::1`、`::ffff:127.0.0.1`） | `utils/validators.py` | 改为先解析成地址对象再按网段语义判定（`0.0.0.0/8`、`127/8`、`224/4`、`240/4`、`::/128`、`::1/128`、`ff00::/8` + IPv4-mapped 递归） |
| 纯数字单标签（`999`）被当合法主机名放行 | `utils/validators.py` | 单标签主机名不得为纯数字 |
| Tailscale 按钮在用户取消确认后永久停在「重启中...」 | `ui/components/tailscale_card.py`、`ui/app.py` | 卡片新增 `set_busy()`，改在确认之后设置忙碌状态 |
| 后台线程直接调用 Tk 的 `after()` 回传结果（非线程安全用法） | `ui/app.py` `_restart_tailscale` | 统一改为 `_control_queue` + 主线程轮询分发；轮询改为常驻（不再只在 Ping 期间自续） |
| `--windowed` 打包后控制台日志 handler 空转（每条日志内部抛异常被吞） | `logger.py` | 仅在 `sys.stdout`/`sys.stderr` 存在时挂载控制台 handler |
| `communicate` 超时后只 `kill()`，未回收管道与进程对象 | `core/ping_worker.py` | 新增 `_kill_current_process()`，`kill()` 后补一次 `communicate()` 收尾 |
| `build.bat` 会删 `*.spec`，与仓库内 `PingTool.spec` 冲突 | — | 本轮未动（待决定：只保留 build.bat） |
| `requirements.txt` 缺测试依赖 | `requirements-dev.txt` | 新增 dev 依赖文件（`-r requirements.txt` + pytest） |

## 新增功能：一键关闭 Windows 防火墙

- 新增 `core/elevation.py`：把「是否管理员」与「UAC 提权批处理」抽成共用模块，
  Tailscale 改为复用（对外 API 与行为不变）。
- 新增 `core/firewall.py`：`query_state()` 读注册表（`EnableFirewall`，普通用户可读，无需提权），
  `disable()` / `enable()` 走 `netsh advfirewall set allprofiles state off|on`；
  未提权时通过 UAC 批处理执行并返回「已发起请求」。
- 新增 `ui/components/firewall_card.py`：状态显示 + 「一键关闭防火墙」「恢复开启」「刷新」三个动作，
  关闭前有安全提示确认框；提权命令发出后等待 6 秒自动复查状态。
- 新增配置项 `firewall_cmd_timeout`（默认 30 秒）；默认窗口高度 550 → 640 以容纳新卡片。
