# 代码标准与验收规范

> 项目：Ping-Tailscale Windows 桌面工具
> 版本：v1.0
> 创建日期：2026-06-07

---

## 一、编码规范

### Python 风格

- 遵循 PEP 8，缩进使用 4 个空格
- 类名：`PascalCase`（如 `PingWorker`）
- 函数/方法名：`snake_case`（如 `start_ping`）
- 常量：`UPPER_SNAKE_CASE`（如 `DATA_FILE`）
- 文件编码：UTF-8

### 注释要求

- 每个类上方有单行说明其职责
- 每个公开方法有简要 docstring
- 复杂逻辑处加行内注释
- 不使用中文变量名，注释可用中文

### 示例

```python
class PingWorker:
    """在独立线程中循环执行 Ping，通过回调返回结果。"""

    def __init__(self, callback: callable):
        """
        Args:
            callback: 每次 ping 完成后调用，接收 dict {"latency": float|None, ...}
        """
        self._callback = callback
        self._running = False
```

## 三、质量标准

### 必须具备

- [ ] 所有按钮点击后都有反馈（视觉变化或状态栏提示）
- [ ] Ping 超时不阻塞 UI（使用独立线程）
- [ ] 窗口关闭时所有线程正确退出
- [ ] 文件不存在时有默认处理（不崩溃）
- [ ] 用户输入有空值校验
- [ ] 异常有 try/except 包裹，并有友好的用户提示

### 建议达到

- [ ] Ping 期间 CPU 占用率 < 5%
- [ ] 窗口启动时间 < 2 秒
- [ ] exe 文件大小 < 50MB

## 四、风险控制

| 风险 | 应对措施 |
|------|----------|
| subprocess 执行 ping 权限不足 | ping 命令通常无需管理员权限 |
| Tailscale 服务名不是 "Tailscale" | 先通过 `sc query` 验证服务名，若有差异则调整 |
| PyInstaller 打包后资源找不到 | 使用 `sys._MEIPASS` 判断是否在打包环境中运行 |
| 杀毒软件拦截 exe | 告知用户添加信任或提交误报 |
| customtkinter 主题异常 | 提供默认主题回退 |

## 五、验收清单

### 功能验收

- [ ] 双击 exe，窗口正常打开，居中显示
- [ ] 下拉框初始为空，可手动输入目标
- [ ] 输入 "8.8.8.8"，点击"添加"，下拉框中出现该目标
- [ ] 选中目标，点击"开始 Ping"，4 个卡片开始更新延迟数据
- [ ] 连续运行 1 分钟，延迟数据持续更新，UI 不卡顿
- [ ] 点击"停止"，Ping 停止，卡片保留最后数据
- [ ] 关闭程序再打开，之前添加的目标仍在下拉框中
- [ ] 点击"重启 Tailscale"，确认后执行，状态栏显示结果
- [ ] 输入不存在的 IP（如 192.0.2.1），点击开始，卡片显示"超时"
- [ ] 快速连续点击"开始-停止-开始"，程序不崩溃

### UI 验收

- [ ] 窗口为浅色主题，淡蓝背景
- [ ] 控件有圆角
- [ ] 字体为 Segoe UI Variable（Win11 默认）
- [ ] 延迟卡片根据数值显示不同颜色
- [ ] 所有文字清晰可读
