# 项目需求文档

> 项目名称：Ping-Tailscale Windows 桌面工具
> 版本：v1.0
> 创建日期：2026-06-07
> 目标用户：完全不懂代码的普通用户

---

## 一、项目背景

用户需要一个 Windows 桌面小工具，能够持续 Ping 指定目标并显示网络延迟，同时具备一键重启 Tailscale 的功能。用户完全不懂代码，因此需要交付为双击即用的单个 `.exe` 文件。

---

## 二、功能需求

### F1 - Ping 功能

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F1.1 | 持续 Ping 用户指定的目标地址（IP 或域名） | P0 |
| F1.2 | 每秒发送 1 次 Ping 请求 | P0 |
| F1.3 | 显示最近 4 次 Ping 的延迟（ms） | P0 |
| F1.4 | 实时计算并显示最近 4 次的平均延迟 | P0 |
| F1.5 | 超时或无响应时显示"超时" | P0 |
| F1.6 | 提供"开始 Ping"和"停止"按钮 | P0 |
| F1.7 | Ping 状态指示灯（绿色=正常，红色=超时/断开） | P1 |

### F2 - 目标管理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F2.1 | 下拉框选择已保存的 Ping 目标 | P0 |
| F2.2 | 手动输入新的目标地址 | P0 |
| F2.3 | 添加目标并持久化保存 | P0 |
| F2.4 | 删除已保存的目标 | P0 |
| F2.5 | 程序关闭后重新打开，目标列表不丢失 | P0 |
| F2.6 | 支持保存 5-10 个目标 | P0 |
| F2.7 | 目标存储为 JSON 文件，位于程序同目录 | P0 |

### F3 - Tailscale 管理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F3.1 | 一键重启 Tailscale 按钮 | P0 |
| F3.2 | 重启前弹出确认对话框，防止误操作 | P1 |
| F3.3 | 显示重启执行结果（成功/失败） | P1 |
| F3.4 | 自动请求管理员权限（UAC） | P0 |

### F4 - UI/UX

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F4.1 | 简洁界面，所有功能在一个窗口内 | P0 |
| F4.2 | Windows 11 风格设计语言 | P0 |
| F4.3 | 淡蓝渐变主题色 | P0 |
| F4.4 | 窗口大小适中，不占用过多屏幕空间 | P1 |
| F4.5 | 底部状态栏显示当前程序状态 | P1 |

### F5 - 交付

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F5.1 | 打包为单个 .exe 文件 | P0 |
| F5.2 | 双击即可运行，无需安装 Python | P0 |
| F5.3 | 不需要命令行窗口（后台运行） | P0 |

---

## 三、非功能需求

- **可靠性**：Ping 超时不会导致程序卡死或崩溃
- **性能**：UI 在 Ping 期间保持流畅响应
- **可维护性**：代码结构清晰，有注释，方便后续修改
- **兼容性**：Windows 10/11 均可运行

---

## 四、约束条件

- 仅支持 Windows 平台
- Tailscale 必须是通过官网安装版安装的（以 Windows 服务形式运行）
- 部分杀毒软件可能误报 PyInstaller 打包的 exe

---

## 五、验收标准

1. 双击 exe 能正常打开窗口
2. 输入 IP/域名后点击"开始 Ping"，能看到延迟数据实时更新
3. 添加目标后关闭再打开，目标仍然存在
4. 点击"重启 Tailscale"能成功重启 Tailscale 服务
5. 持续 Ping 期间 UI 不卡顿
6. 关闭窗口后程序完全退出，不留后台进程
