# 设计规范

> 项目：Ping-Tailscale Windows 桌面工具
> 版本：v1.0
> 创建日期：2026-06-07

---

## 一、设计原则

1. **简洁至上**：一个窗口完成所有操作，无多余菜单/弹窗
2. **一目了然**：核心数据（延迟）突出显示，辅助功能低调放置
3. **Win11 对齐**：圆角、间距、字体跟随 Windows 11 设计语言
4. **零学习成本**：控件功能自解释，无需帮助文档

---

## 二、配色方案

### 主色调：淡蓝渐变

| 用途 | 色值 | 说明 |
|------|------|------|
| 窗口背景 | `#E8F4FD` → `#D0E8F8` | 从上到下淡蓝渐变 |
| 卡片/面板背景 | `#FFFFFF` | 白色，带透明度 95% |
| 主按钮 | `#3B82F6` | 蓝色（Bootstrap Blue） |
| 主按钮 hover | `#2563EB` | 深蓝 |
| 停止/删除按钮 | `#EF4444` | 红色 |
| 停止/删除 hover | `#DC2626` | 深红 |
| 成功/正常 | `#10B981` | 绿色 |
| 警告/超时 | `#F59E0B` | 琥珀色 |
| 错误 | `#EF4444` | 红色 |
| 文字主色 | `#1E293B` | 深灰蓝 |
| 文字次要 | `#64748B` | 中灰 |
| 边框 | `#CBD5E1` | 浅灰蓝 |

### 渐变色定义

```python
# 主背景渐变
GRADIENT_START = "#E8F4FD"  # 顶部
GRADIENT_END   = "#C8E4F8"  # 底部（稍深一点的蓝）

# 标题栏
TITLE_BG = "#DBEAFE"        # 浅蓝，不分渐变
```

## 三、字体规范

| 场景 | 字体 | 大小 | 粗细 | 说明 |
|------|------|------|------|------|
| 窗口标题 | Segoe UI Variable | 18px | Bold | 标题栏文字 |
| 区块标题 | Segoe UI Variable | 15px | SemiBold | 功能区域标题 |

> 回退方案：若系统不支持 Segoe UI Variable，自动降级为 `Segoe UI` → `Microsoft YaHei`

## 六、交互规范

### 按钮状态

| 状态 | 开始 Ping | 停止 | 重启 Tailscale |
|------|-----------|------|---------------|
| 空闲（未开始） | 可点击 | 灰色禁用 | 可点击 |
| 正在 Ping | 灰色禁用 | 可点击 | 可点击 |
| 操作执行中 | — | — | 显示"重启中..." |

### 延迟卡片颜色

| 延迟范围 | 卡片边框/文字颜色 | 含义 |
|----------|-------------------|------|
| 0-30ms | `#10B981` 绿色 | 优秀 |
| 31-80ms | `#3B82F6` 蓝色 | 良好 |
| 81-150ms | `#F59E0B` 琥珀色 | 一般 |
| >150ms | `#EF4444` 红色 | 较差 |
| 超时 | `#EF4444` 红色 + 灰色背景 | 无响应 |

### Ping 状态指示灯

- 🟢 绿色圆点 + "正在 Ping: xxx"：正常运行
- 🔴 红色圆点 + "已停止"：已手动停止
- 🟡 黄色圆点 + "Ping 超时"：连续多次超时

## 七、组件规范

### 按钮

```python
# 主操作按钮（开始 Ping、重启 Tailscale）
CTkButton(
    width=140, height=36,
    corner_radius=8,
    fg_color="#3B82F6",
    hover_color="#2563EB",
    font=("Segoe UI Variable", 14)
)

# 次要按钮（添加、删除）
CTkButton(
    width=60, height=32,
    corner_radius=6,
    font=("Segoe UI Variable", 13)
)

# 停止按钮
CTkButton(
    fg_color="#EF4444",
    hover_color="#DC2626"
)
```

### 延迟卡片

```python
# 卡片使用 CTkFrame
CTkFrame(
    corner_radius=10,
```
